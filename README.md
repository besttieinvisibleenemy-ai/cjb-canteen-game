# CJB Staff Canteen Game

A single-file HTML5 time-management game about running the staff canteen at Coimbatore Airport (CJB). Open the GitHub Pages site to play in a browser.

The main page (index.html) is version 8: a JARVIS-style instructor with live commentary (on/off, optional voice, your own lines), a works list per employee, staff renaming, and shift/day inspections scored from the simulation. Version 7 is kept as v7.html and version 6 as v6.html.
