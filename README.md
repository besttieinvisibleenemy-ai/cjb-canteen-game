# CJB Staff Canteen Game

A single-file HTML5 time-management game about running the staff canteen at Coimbatore Airport (CJB). Open the GitHub Pages site to play in a browser.

The main page (index.html) is version 7: per-shift visitor input with one-tap simulation, shift sales and P&L, an 8 h split-shift roster, and a river with a boat and crew. Version 6 is kept as v6.html.
